# 噜噜的小商店 · LULU ORANGE SHOP

橙黄色暖萌主题的单页商店，店主栩栩（INFP · 双鱼座 · 2.19）。

## 内容

- 开屏视频：噜噜走进暖色调小屋，可点「跳过」直接进店
- 01 挑东西：20 只噜噜周边，分类筛选、加入购物袋
- 02 店主须知：规矩 / 喜点 / 雷点，已阅确认
- 03 回忆陈列：日常照片占位卡片
- 04 结账小票：清单、合计、收银人、单号

## 本地运行

单文件自包含 HTML，直接用浏览器打开 `index.html` 即可；素材在 `assets/` 目录。

## 技术

- 原生 HTML / CSS / JavaScript，无框架
- 竖版 9:16 背景与开屏视频，响应式适配手机与桌面
